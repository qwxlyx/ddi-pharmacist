# ИИ-клинический фармаколог

Мультиагентное приложение для проверки лекарственной схемы (DDI-анализ) по
открытым источникам FDA/NLM. Учебный проект по дисциплине «Прикладная
информатика в медицине».

## Источники данных

| Источник | Роль | API |
|---|---|---|
| RxNorm (NLM) | нормализация названий ЛС, действующие вещества | RxNav REST, без ключа |
| DailyMed (NLM) | официальные лейблы FDA (SPL): взаимодействия, противопоказания, дозировки, предупреждения | REST v2, без ключа |
| FAERS через openFDA (FDA) | сигналы фармаконадзора: топ нежелательных явлений по препарату | openFDA `drug/event.json`, без ключа |

## Архитектура (мультиагентность)

1. **Агент нормализации (RxNorm)** — переводит ввод пользователя в канонические
   RxCUI и действующие вещества.
2. **Агент лейблов (DailyMed)** — для каждого препарата находит SPL-лейбл и
   извлекает клинические секции (boxed warning, contraindications, warnings,
   precautions, drug interactions, dosage…).
3. **Агент фармаконадзора (FAERS)** — запрашивает топ реакций и число сообщений
   по каждому препарату.
4. **DDI-движок** — перекрёстный анализ: ищет упоминания каждого действующего
   вещества в текстах лейблов остальных препаратов, а серьёзность оценивает
   по лексическим правилам (contraindicated → avoid → caution/monitor…).

## Запуск локально

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Развёртывание в веб (Streamlit Community Cloud)

1. Залейте папку проекта в GitHub-репозиторий (`app.py`, `agents.py`,
   `requirements.txt`).
2. На https://share.streamlit.io выберите репозиторий, файл `app.py`, нажмите
   Deploy.
3. Приложение получает публичный URL — его можно отправить преподавателю.

> Примечание: api.fda.gov (openFDA) может блокироваться некоторыми
> провайдерами (в т.ч. из РФ). DailyMed и RxNorm работают из любой сети;
> раздел FAERS корректно работает при развёртывании на Streamlit Cloud
> (серверы в США).

## Ограничения

Сервис учебный и не является медицинской рекомендацией. Оценка серьёзности
взаимодействия — лексическая эвристика по тексту лейбла, а не клиническая
экспертиза.
